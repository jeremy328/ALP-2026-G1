## 📖 Descripción

Este proyecto tiene como objetivo demostrar el uso de **ficheros en Java**, aplicando diferentes clases y métodos para crear archivos y escribir información en ellos.

El manejo de ficheros es una característica fundamental en el desarrollo de aplicaciones, ya que permite almacenar información de forma permanente para poder utilizarla posteriormente.

---

## 🎯 Objetivo

Desarrollar programas en **Java** que permitan **crear y escribir información en ficheros**, utilizando las herramientas proporcionadas por el lenguaje para gestionar archivos de manera eficiente.

---

## 🧠 Temas abordados

- 📂 Creación de ficheros.
- ✍️ Escritura de información en archivos.
- 📄 Manejo de archivos de texto.
- ⚠️ Control de errores mediante excepciones.
- 🔄 Uso de bloques `try-catch`.
- 💾 Almacenamiento permanente de información.

## 📚 Conceptos importantes

### 📁 `File`

Representa un archivo o directorio dentro del sistema.

### ✍️ `FileWriter`

Permite escribir caracteres dentro de un archivo.

### 📝 `BufferedWriter`

Facilita y optimiza la escritura de información.

### ⚠️ `IOException`

Es una excepción que puede producirse durante las operaciones de entrada y salida de datos.
